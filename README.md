# BharatMandi - Public APMC Mandi Rates CDN

Daily automated commodity price dataset powering **BharatMandi (भारत मंडी)**.

## Live Endpoints

- **Fast Global CDN**: `https://cdn.jsdelivr.net/gh/systemiclogics-beep/mandi-rates@main/today.json`
- **Raw GitHub Endpoint**: `https://raw.githubusercontent.com/systemiclogics-beep/mandi-rates/main/today.json`
- **GitHub Pages**: `https://systemiclogics-beep.github.io/mandi-rates/today.json`

## Update Schedule
- Twice daily at **11:30 AM IST** (morning arrival rates) and **03:30 PM IST** (closing auction rates).
- Automated via GitHub Actions.
